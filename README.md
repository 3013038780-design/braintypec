## 怎样理解这些研究

每条证据尽量区分：仪器性能、任务或状态指标、干预效果和真实使用表现。第一作者、通讯作者及共同作者按可核对的信息分别标注；仅末位署名不自动认定为通讯作者。论文检索、摘要核对和正文阅读的范围保留在记录中。

赵教授的硬件、配准、信号处理和场景研究是团队的重要知识基础；当前公司整机具备哪些能力、公司拥有哪些商业使用权、产品能为用户带来什么收益，仍需分别对应到可复现的结果。
